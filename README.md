# Agentic operating system: architecture and design documents

Architecture and design documents for an agentic operating system: a Chief of Staff for every person, a systems
engineering organization, and factories by type of work, with a human decision at every protected effect (approve,
merge, send, spend, publish).

| File | What it is |
|---|---|
| `ARCHITECTURE_PROMPT.md` | A prompt that has an architecture-capable coding agent design the system for your organization from these documents |
| `docs/ARCHITECTURE.md` | The paradigm and its parts |
| `docs/OPERATING_PRINCIPLES.md` | The rules every part follows |
| `docs/GLOSSARY.md` | The terms |
| `design/cps-research-directorate/` | A reference organization (a cyber-physical systems research directorate): overview, org chart, roles and entitlements |
| `design/cps-research-directorate/compute-plane/` | An example compute-plane design (topology, memory fit, gateway routes, gaps; Mermaid and SysML v2), generated from an example inventory |

These are design documents only. The implementation (generator, templates, runtime) is not part of this release.
